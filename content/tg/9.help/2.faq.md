Ҷавобҳои кӯтоҳ бо истинод ба саҳифаи пурра. Агар саволи шумо дар ин ҷо набошад, ба [Ҳалли мушкилот](/tg/help/troubleshooting) нигаред ё дар саҳифаи лозимӣ бахши **Агар чизе хато шуд**-ро бинед.

## Тиҷорати шумо

::accordion
  :::accordion-item{label="Оё Partha-ро танҳо барои анбор, бе фурӯш, истифода бурдан мумкин аст?" icon="i-lucide-warehouse"}
  Бале. :term[Нуқта]{id="point"} метавонад анборе бошад, ки ҳеҷ чиз намефурӯшад. Кассаро дар ин нуқта хомӯш кунед: нигаред ба [Нуқта илова кунед](/tg/business/add-point).
  :::

  :::accordion-item{label="Оё кишвари тиҷоратро тағйир додан мумкин аст?" icon="i-lucide-globe"}
  Не. Кишвар ҳангоми сохтани тиҷорат интихоб мешавад. Агар нодуруст бошад, тиҷорати нав бо кишвари дуруст созед ва нодурустро нест кунед: нигаред ба [Танзимоти тиҷоратро тағйир диҳед](/tg/business/business-settings).
  :::

  :::accordion-item{label="Барои фаъол кардани ААИ чӣ лозим аст?" icon="i-lucide-percent"}
  Бояд ҳамчун пардохткунандаи :term[ААИ]{id="vat"} сабт шуда бошед ва рақами андозро нависед. Нигаред ба [ААИ-ро танзим кунед](/tg/business/set-up-vat).
  :::

  :::accordion-item{label="Тариф ё пардохти Partha-ро дар куҷо бинам?" icon="i-lucide-credit-card"}
  Саҳифаи **Тариф** имрӯз холист ва барнома пардохт қабул намекунад. Нигаред ба [Тариф ва пардохт](/tg/business/plan-and-billing).
  :::

  :::accordion-item{label="Рамзро фаромӯш кардам." icon="i-lucide-key-round"}
  Рамзро дар барнома ҳоло барқарор кардан мумкин нест. Нигаред ба [Профили шумо ва даромадан](/tg/business/your-profile).
  :::

  :::accordion-item{label="Оё Partha бо дастгоҳи кассаи андозӣ дар Тоҷикистон кор мекунад?" icon="i-lucide-map-pin"}
  Ҳоло не. Нигаред ба [Андозҳо ва чекҳо дар Тоҷикистон](/tg/markets/tajikistan/taxes).
  :::
::


## Анбор

::accordion
  :::accordion-item{label="Мол қабул кардам, вале бақия зиёд нашуд." icon="i-lucide-package-plus"}
  Қабули мол ҳанӯз :term[пешнавис]{id="draft"} аст. Онро кушоед ва **Ба анбор илова кардан**-ро пахш кунед. Нигаред ба [Аз таъминкунанда мол қабул кунед](/tg/warehouse/receive-goods).
  :::

  :::accordion-item{label="Дар қабули аллакай иловашуда хато кардам." icon="i-lucide-undo-2"}
  Онро тағйир додан мумкин нест, вале бекор кардан ва аз нав сабт кардан мумкин аст. Бекоршуда дар рӯйхат мемонад. Нигаред ба [Аз таъминкунанда мол қабул кунед](/tg/warehouse/receive-goods).
  :::

  :::accordion-item{label="Чӣ тавр огоҳӣ гирам, вақте мол тамом мешавад?" icon="i-lucide-bell"}
  Дар мол **Бақияи ҳадди ақал**-ро нависед. Нигаред ба [Молҳоро илова кунед](/tg/warehouse/add-items) ва [Бақияи молро санҷед](/tg/warehouse/check-stock).
  :::

  :::accordion-item{label="Чӣ тавр молро аз анбор ба мағоза фиристам?" icon="i-lucide-arrow-left-right"}
  Интиқолро сабт кунед. Мағоза молро вақте расид, қабул мекунад. Нигаред ба [Молро байни нуқтаҳо интиқол диҳед](/tg/warehouse/move-goods).
  :::
::

## Нарх ва фоида

::accordion
  :::accordion-item{label="Мол дар касса нарх надорад." icon="i-lucide-tag"}
  Кассир метавонад нархро барои ҳар фурӯш нависад. Барои ин ки ин нашавад, нарх гузоред: нигаред ба [Нарх гузоред](/tg/prices/set-prices).
  :::

  :::accordion-item{label="Чаро фоидаи ман аз ҳад зиёд менамояд?" icon="i-lucide-coins"}
  Нархи хариди як қисми мол маълум нест, масалан моле, ки ҳамчун **Моли зуд** навишта шудааст. Нигаред ба [Фоидаи худро бинед](/tg/reports/profit).
  :::

  :::accordion-item{label="Оё усули таннархро баъд тағйир додан мумкин аст?" icon="i-lucide-calculator"}
  Баъд аз аввалин ҳаракати мол не. Нигаред ба [Partha таннархро чӣ тавр ҳисоб мекунад](/tg/reports/how-cost-works).
  :::
::

## Касса

::accordion
  :::accordion-item{label="Чаро фурӯшро оғоз карда наметавонам?" icon="i-lucide-key-round"}
  Барои фурӯш навбати кории кушода лозим аст. Нигаред ба [Навбати корӣро кушоед](/tg/cashier/open-shift).
  :::

  :::accordion-item{label="Оё пардохти кортро қабул кардан мумкин аст?" icon="i-lucide-credit-card"}
  Касса ба терминали корт пайваст нест. Пулро дар терминал гиред, баъд фурӯшро анҷом диҳед. Нигаред ба [Пардохт гиред](/tg/cashier/take-payment).
  :::

  :::accordion-item{label="Оё пули як қисми молҳои чекро баргардонидан мумкин аст?" icon="i-lucide-receipt"}
  Не. Пули тамоми чек баргардонида мешавад ва танҳо як маротиба. Нигаред ба [Пули фурӯшро баргардонед](/tg/cashier/refund).
  :::

  :::accordion-item{label="Ҳангоми бастани навбат пул мувофиқ намеояд." icon="i-lucide-lock"}
  Боз шуморед, фурӯшҳо ва баргардонидани пулро санҷед ва сабабро дар эзоҳ нависед. Нигаред ба [Навбати корӣро бибандед](/tg/cashier/close-shift).
  :::
::

## Гурӯҳи шумо

::accordion
  :::accordion-item{label="Оё ҳамкор таннарх ва фоидаи маро дида метавонад?" icon="i-lucide-shield-check"}
  Танҳо агар ба ӯ дастрасии **Дидани нарх ва фоида**-ро диҳед. Нигаред ба [Нақшҳо ва он чи иҷозат додан мумкин аст](/tg/team/roles-and-permissions).
  :::

  :::accordion-item{label="Шахс рафт. Дастрасиашро чӣ тавр бибандам?" icon="i-lucide-user-x"}
  Барои ҳар нуқта **Дастрасӣ нест**-ро интихоб кунед. Нигаред ба [Тағйир диҳед, ки ҳамкор чӣ карда метавонад](/tg/team/change-access).
  :::
::
