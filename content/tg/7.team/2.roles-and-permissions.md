Вақте ҳамкорро даъват мекунед, интихоб мекунед, ки ӯ чӣ кор карда метавонад. Ин аз рӯи **нақш** барои ҳар нуқта анҷом меёбад, ва як-як бандҳоро илова ё хориҷ кардан мумкин аст. Дар ин ҷо ҳар чизе навишта шудааст, ки иҷозат додан мумкин аст.

## Нақшҳо

Нақш маҷмӯаи тайёри дастрасӣ барои як нуқта аст. Онро дар рӯйхати **Нақш**-и нуқта интихоб кунед. Баъд метавонед як-як бандҳоро тағйир диҳед, ва нақш **Худсохт** мешавад.

| Нақш | Барои кӣ |
| --- | --- |
| **Кассир** | Шахсе, ки дар касса мефурӯшад |
| **Бинандаи анбор** | Шахсе, ки танҳо анборро мебинад |
| **Мудири анбор** | Шахсе, ки анборро пеш мебарад |
| **Дастрасӣ нест** | Шахсе, ки дар ин нуқта кор намекунад |
| **Худсохт** | Шумо ҳар бандро худатон интихоб мекунед |

## Барои тамоми тиҷорат

Инҳо дар ҳамаи нуқтаҳо амал мекунанд. Аксари ҳамкорон ба ягонтои онҳо ниёз надоранд.

| Бахш | Чӣ иҷозат додан мумкин аст |
| --- | --- |
| Маълумоти тиҷорат | Дидани рӯйхат, Кушодани тафсилот, Илова кардан, Тағйир додан, Нест кардан |
| Нуқтаҳо | Дидани рӯйхат, Кушодани тафсилот, Илова кардан, Тағйир додан, Нест кардан |
| Кормандон | Дидани рӯйхат, Кушодани тафсилот, Илова кардан, Тағйир додан, Нест кардан, Тағйири дастрасӣ |
| Нархҳо | Дидани рӯйхат, Кушодани тафсилот, Илова кардан, Тағйир додан, Нест кардан, Барқарор кардан |

## Дар ҳар нуқта: Касса

| Бахш | Чӣ иҷозат додан мумкин аст |
| --- | --- |
| Молҳо дар касса | Кушодани тафсилот |
| Фурӯшҳо | Илова кардан, Кушодани тафсилот, Баргардонидани пул, Дидани нарх ва фоида |
| Навбатҳои корӣ | Оғоз кардан, Кушодани тафсилот, Бастан |
| PIN-кодҳои кассирон | Идора кардан |
| Танзимоти чек | Кушодани тафсилот, Тағйир додан |

::tip
**Дидани нарх ва фоида** дастрасиест, ки таннарх ва фоидаро нишон медиҳад. Онро танҳо ба касоне диҳед, ки метавонанд фоидаи шуморо донанд. Бе он касса ва саҳифаҳои нарх таннарх ва фоидаро пинҳон мекунанд.
::
