Вақте шахсро илова мекунед, интихоб мекунед, ки ӯ чӣ кор карда метавонад. Ин аз рӯи **нақш** барои ҳар нуқта анҷом меёбад, ва як-як бандҳоро илова ё хориҷ кардан мумкин аст. Дар ин ҷо ҳар чизе навишта шудааст, ки иҷозат додан мумкин аст.

## Нақшҳо

Нақш маҷмӯаи тайёри дастрасӣ барои як нуқта аст. Онро дар рӯйхати **Нақш**-и нуқта интихоб кунед. Баъд метавонед як-як бандҳоро тағйир диҳед, ва нақш **Худсохт** мешавад. Вақте ки мо ба нақш дастрасии нав илова мекунем, онро ҳамаи касоне мегиранд, ки дар нуқта ин нақшро доранд. Бандҳое, ки худатон интихоб кардед, дигар намешаванд.

| Нақш | Барои кӣ |
| --- | --- |
| **Кассир** | Шахсе, ки дар касса мефурӯшад |
| **Бинандаи анбор** | Шахсе, ки танҳо анборро мебинад |
| **Мудири анбор** | Шахсе, ки анборро пеш мебарад |
| **Ҳисобкунандаи анбор** | Шахсе, ки молро ҳисоб мекунад, вале бақияро намебинад |
| **Дастрасӣ нест** | Шахсе, ки дар ин нуқта кор намекунад |
| **Худсохт** | Шумо ҳар бандро худатон интихоб мекунед |

## Барои тамоми тиҷорат

Инҳо дар ҳамаи нуқтаҳо амал мекунанд. Аксари ҳамкорон ба ягонтои онҳо ниёз надоранд.

| Бахш | Чӣ иҷозат додан мумкин аст |
| --- | --- |
| Маълумоти тиҷорат | Дидани рӯйхат, Кушодани тафсилот, Илова кардан, Тағйир додан, Нест кардан |
| Нуқтаҳо | Дидани рӯйхат, Кушодани тафсилот, Илова кардан, Тағйир додан, Нест кардан |
| Кормандон | Дидани рӯйхат, Кушодани тафсилот, Илова кардан, Тағйир додан, Нест кардан, Тағйири дастрасӣ |
| Нархҳо | Дидани рӯйхат, Кушодани тафсилот, Илова кардан, Тағйир додан, Нест кардан, Барқарор кардан |
| Журнали аудит | Дидани журнали аудит |
| Қарз ба таъминкунандагон | Кушодани тафсилот |
| Пардохт ба таъминкунандагон | Илова кардан, Бекор кардан |

::note
**Дидани журнали аудит** ба сабти амалҳои муҳим дар тиҷорат дастрасӣ медиҳад, масалан, кӣ ва кай ҳуҷҷати анборро бекор ё нест кардааст. Ин дастрасӣ назди соҳиби тиҷорат аст. Он ба ҳеҷ нақш дохил намешавад, бинобар ин онро танҳо ба касе диҳед, ки ба ӯ боварӣ доред. Экрани **Таърих**, ки дар он сабтро хондан мумкин аст, баъдтар пайдо мешавад. То он вақт ин дастрасӣ дар барнома чизеро тағйир намедиҳад.
::

::note
**Қарз ба таъминкунандагон** ва **Пардохт ба таъминкунандагон** иҷозат медиҳанд бинед, ки тиҷорат ба таъминкунандагон чӣ қадар қарздор аст, пардохтҳоро сабт ва бекор кунед. Дар аввал онҳо танҳо назди соҳиб ҳастанд, ҳеҷ нақш онҳоро дар бар намегирад. Нигаред ба [Ба таъминкунандагон пардохт кунед](/tg/warehouse/pay-suppliers#who-can-do-what).
::

## Дар ҳар нуқта: Анбор

| Бахш | Чӣ иҷозат додан мумкин аст |
| --- | --- |
| Анбор | Кушодани тафсилот |
| Молҳо | Дидани рӯйхат, Кушодани тафсилот, Илова кардан, Тағйир додан, Нест кардан, Барқарор кардан |
| Тоифаҳо | Дидани рӯйхат, Кушодани тафсилот, Илова кардан, Тағйир додан, Нест кардан, Барқарор кардан |
| Таъминкунандагон | Дидани рӯйхат, Кушодани тафсилот, Илова кардан, Тағйир додан, Нест кардан, Барқарор кардан |
| Қабули мол | Дидани рӯйхат, Кушодани тафсилот, Илова кардан, Тағйир додан, Нест кардан, Қабул кардан, Бекор кардан, Барқарор кардан |
| Баровардани мол | Дидани рӯйхат, Кушодани тафсилот, Илова кардан, Тағйир додан, Нест кардан, Баровардан, Бекор кардан, Барқарор кардан |
| Интиқол | Дидани рӯйхат, Кушодани тафсилот, Илова кардан, Тағйир додан, Нест кардан, Фиристодан, Қабул кардан, Бекор кардан, Барқарор кардан |
| Бақияи мол | Дидани рӯйхат, Кушодани тафсилот |
| Баҳисобгирии мол | Дидани рӯйхат, Кушодани тафсилот, Илова кардан, Тағйир додан, Нест кардан, Барқарор кардан, Ҳисоб кардан, Санҷидан ва тасдиқ кардан, Навсозии бақия, Бекор кардан |

::note
Дар бахши **Баҳисобгирии мол** дастрасии **Бекор кардан** имкон медиҳад, ки натиҷаи баҳисобгирие, ки бақияро аллакай нав кардааст, бекор карда шавад (**Бекор кардани натиҷа**). Ягон нақш онро надорад, бинобар ин инро танҳо соҳиб мекунад, агар худаш ин дастрасиро ба касе надиҳад. Барои бекор кардани баҳисобгирӣ пеш аз тағйири бақия дастрасии **Тағйир додан** лозим аст. Нақши **Ҳисобкунандаи анбор** ҳисоб карда метавонад, вале бақия, қабул ва баровардани молро намебинад, бинобар ин ҳисоб «нобино» мемонад. Нигаред ба [Моли худро шуморед](/tg/warehouse/stock-count#blind-counting).
::

## Дар ҳар нуқта: Касса

| Бахш | Чӣ иҷозат додан мумкин аст |
| --- | --- |
| Молҳо дар касса | Кушодани тафсилот |
| Фурӯшҳо | Илова кардан, Кушодани тафсилот, Баргардонидани пул, Дидани нарх ва фоида |
| Навбатҳои корӣ | Оғоз кардан, Кушодани тафсилот, Бастан, Дидани ҳамаи навбатҳо |
| PIN-кодҳои кассирон | Идора кардан |
| Танзимоти чек | Кушодани тафсилот, Тағйир додан |

::note
Бе дастрасии **Дидани ҳамаи навбатҳо** кассир танҳо навбати худро мекушояд. Навбатҳои ҳамкорон аз ӯ пинҳон аст. Соҳибон ва маъмурони нуқта ҳамеша ҳамаи навбатҳоро мебинанд. Агар менеҷер нақши **Худсохт** дошта бошад, барояш **Дидани ҳамаи навбатҳо**-ро қайд кунед, то ҷамъҳои навбатҳои тамоми нуқтаро бинад.
::

::tip
**Дидани нарх ва фоида** дастрасиест, ки таннарх ва фоидаро нишон медиҳад. Онро танҳо ба касоне диҳед, ки метавонанд фоидаи шуморо донанд. Бе он касса ва саҳифаҳои нарх таннарх ва фоидаро пинҳон мекунанд.
::
