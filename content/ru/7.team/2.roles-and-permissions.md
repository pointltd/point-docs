Когда вы добавляете человека, вы выбираете, что ему можно делать. Это делается по **ролям** для каждой точки, и можно добавлять или убирать отдельные пункты. Здесь перечислено всё, что можно разрешить.

## Роли

Роль — это готовый набор доступа для одной точки. Выберите её в списке **Роль** у точки. После этого можно менять отдельные пункты, и роль станет **Своим набором**.

| Роль | Для кого |
| --- | --- |
| **Кассир** | Человек, который продаёт на кассе |
| **Просмотр склада** | Человек, который только смотрит склад |
| **Заведующий складом** | Человек, который ведёт склад |
| **Нет доступа** | Человек, который не работает на этой точке |
| **Свой набор** | Вы сами выбираете каждый пункт |

## Для всего бизнеса

Это действует на всех точках. Большинству коллег ничего из этого не нужно.

| Раздел | Что можно разрешить |
| --- | --- |
| Данные бизнеса | Видеть список, Открывать, Добавлять, Менять, Удалять |
| Точки | Видеть список, Открывать, Добавлять, Менять, Удалять |
| Команда | Видеть список, Открывать, Добавлять, Менять, Удалять, Менять доступ |
| Цены | Видеть список, Открывать, Добавлять, Менять, Удалять, Восстанавливать |

## На каждой точке: Склад

| Раздел | Что можно разрешить |
| --- | --- |
| Склад | Открывать |
| Товары | Видеть список, Открывать, Добавлять, Менять, Удалять, Восстанавливать |
| Категории | Видеть список, Открывать, Добавлять, Менять, Удалять, Восстанавливать |
| Поставщики | Видеть список, Открывать, Добавлять, Менять, Удалять, Восстанавливать |
| Приёмка товара | Видеть список, Открывать, Добавлять, Менять, Удалять, Принимать, Отменять, Восстанавливать |
| Списания | Видеть список, Открывать, Добавлять, Менять, Удалять, Списывать, Отменять, Восстанавливать |
| Перемещения | Видеть список, Открывать, Добавлять, Менять, Удалять, Отправлять, Принимать, Отменять, Восстанавливать |
| Остатки | Видеть список, Открывать |

## На каждой точке: Касса

| Раздел | Что можно разрешить |
| --- | --- |
| Товары на кассе | Открывать |
| Продажи | Добавлять, Открывать, Возвращать деньги, Видеть стоимость и прибыль |
| Смены | Начинать, Открывать, Закрывать |
| PIN-коды кассиров | Управлять |
| Настройки чека | Открывать, Менять |

::tip
**Видеть стоимость и прибыль** — доступ, который показывает себестоимость и прибыль. Давайте его только тем, кому можно знать вашу наценку. Без него касса и страницы цен скрывают себестоимость и прибыль.
::
