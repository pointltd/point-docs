When you add a person, you choose what they can do. You do it by **role** for each point, and you can add or remove single items. This page lists everything you can allow.

## Roles

A role is a ready set of access for one point. Choose it in the **Role** list of a point. You can then change single items, and the role becomes **Custom**.

| Role | For whom |
| --- | --- |
| **Cashier** | A person who sells at the cash desk |
| **Warehouse viewer** | A person who only looks at the warehouse |
| **Warehouse manager** | A person who runs the warehouse |
| **No access** | A person who does not work at this point |
| **Custom** | You choose each item yourself |

## For the whole business

These apply to every point. Most colleagues need none of them.

| Area | What you can allow |
| --- | --- |
| Business details | See the list, Open details, Add, Edit, Delete |
| Points | See the list, Open details, Add, Edit, Delete |
| Team | See the list, Open details, Add, Edit, Delete, Change access |
| Prices | See the list, Open details, Add, Edit, Delete, Restore |

## At each point: Warehouse

| Area | What you can allow |
| --- | --- |
| Warehouse | Open details |
| Products | See the list, Open details, Add, Edit, Delete, Restore |
| Categories | See the list, Open details, Add, Edit, Delete, Restore |
| Suppliers | See the list, Open details, Add, Edit, Delete, Restore |
| Goods received | See the list, Open details, Add, Edit, Delete, Receive, Cancel, Restore |
| Write-offs | See the list, Open details, Add, Edit, Delete, Write off, Cancel, Restore |
| Transfers | See the list, Open details, Add, Edit, Delete, Send, Receive, Cancel, Restore |
| Stock levels | See the list, Open details |

## At each point: Cash desk

| Area | What you can allow |
| --- | --- |
| Products at the till | Open details |
| Sales | Add, Open details, Refund, See costs and profit |
| Shifts | Start, Open details, Close |
| Cashier PINs | Manage |
| Receipt settings | Open details, Edit |

::tip
**See costs and profit** is the access that shows costs and profit. Give it only to people who may know your margins. Without it, the cash desk and the price pages hide the cost and the profit.
::
