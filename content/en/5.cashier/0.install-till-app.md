The Partha till app is a full-screen cash desk for a Windows computer in your shop. You download it from Partha and connect it with a short code.

::note
You need the **Cash desk** access to do this. Ask the owner of the business if you don't see it.
::

## Steps

::steps{level="3"}
### Open the Tills page
In Partha, open your store, then **Cash desk** → **Tills**. You will see the card **Partha till for Windows**.

### Download the app
Press **Download** on the card. A file named `Partha-Till-Setup.exe` goes to the Downloads folder of the computer. If you are not on the shop's computer, send the file to it or open this page there.

:::screenshot{src="cashier/install-till-app-1" alt="The Tills page with the Download button"}
:::

### Install it
Open the file on the shop's Windows computer and wait. When it finishes, the app opens by itself.

Windows may ask you to confirm. Choose **More info** → **Run anyway**. This is normal: the app is new and Windows does not know it yet.

### Type the code in Partha
The app shows a code. In Partha, on the **Tills** page, press **Add a till** and type that code.

The till is ready when it appears in the list as **Active**.
::

## If something went wrong

- **The code is not accepted.** Codes stop working after a short time. Close the app, open it again and type the new code.
- **There is no Download button.** Your Partha does not have the Windows app yet. Ask us through the help page.
