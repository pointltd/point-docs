The Partha Till app is a full-screen cash desk for a Windows computer at your point. You download it from Partha and connect it with a short code.

::note
You need the **Cash desk** access to do this. Ask the owner of the business if you don't see it.
::

## Steps

::steps{level="3"}
### Open the Tills page
In Partha, open your store, then **Cash desk** → **Tills**. You will see the card **Partha Till for Windows**.

### Download the app
Press **Download** on the card. A file named `Partha-Till-Setup-en.exe` goes to the Downloads folder of the computer. The end of the name is the language you use Partha in (`-en`, `-ru` or `-tg`), and the installer speaks that language. If you are not on the point's computer, send the file to it or open this page there. Keep the name as it is: the installer reads the language from it.

:::screenshot{src="cashier/install-till-app-1" alt="The Tills page with the Download button"}
:::

### Install it
Open the file on the point's Windows computer and wait. When it finishes, the app opens by itself.

Windows may say the publisher is unknown, because we are still getting the installer signed. Continue only if you downloaded the file from the Tills page in Partha. If you are not sure where the file came from, do not open it.

### Type the code in Partha
The app shows a code. In Partha, on the **Tills** page, press **Add a till** and type that code.

The till is ready when it appears in the list as **Active**.
::

The app starts in the language of the installer, so a Partha in Russian gives a till in Russian. If you use Partha in Tajik, the installer window is shown in Russian and the app itself is in Tajik.

## Change the language of the till

On the code screen, on the **Who is selling?** screen and in the till menu you will see three buttons: **English**, **Русский** and **Тоҷикӣ**. Press the one you want. Nobody has to sign in, and no manager PIN is needed. The till remembers the language on this computer, also after you close the app.

## Sign in at the till

When the till is **Active**, it shows **Who is selling?**. A new till has nobody on the list yet. Each person signs in with their own PIN, and a PIN is made from a one-time setup code.

::steps{level="3"}
### Give yourself a setup code
In Partha, open **Team**. Find your own name, as the owner of the business you are already there, and press the ticket icon (**Give a new code**). The code works once, for 24 hours.

### Choose your PIN at the till
The till checks the list by itself every few seconds, so you do not need to restart the app. Press your name, type the setup code, then choose a PIN of 4 to 8 digits and type it again.
::

Your colleagues need the **Cashier** role for this point and a setup code of their own. See [Let people sign in at the till](/en/team/till-sign-in).

## Close the app or leave full screen

- **A new till that nobody has a PIN on yet:** press **Close the app** on the **Who is selling?** screen.
- **Otherwise a manager does it.** On the cash desk, open the till menu, press **Close the till app (manager)** and type the manager's PIN.
- **To use other programs on the computer,** a manager opens the same menu and presses **Leave full screen (manager)**. Press **Go full screen** to come back.

## If something went wrong

- **The code is not accepted.** A connection code works for a few minutes. The app then says "The code has expired". Press **Get a new code** and type the new one in Partha.
- **The till says "Nobody can sign in at this till yet".** Nobody on your team has a setup code or a PIN for this point. Give yourself a code in **Team**, as described in **Sign in at the till** above, and see [Let people sign in at the till](/en/team/till-sign-in) for your colleagues.
- **There is no Download button.** Your Partha does not have the Windows app yet. Ask us through the help page.
